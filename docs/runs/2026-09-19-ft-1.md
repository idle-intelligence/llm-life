# Variant B LoRA fine-tune, smoke run 1 — 2026-09-19

First fine-tune of CONCEPT.md §5. What is being asked: does the per-cell
cross-entropy on true Life move variant B's per-case recall for `birth` and
`survive-*` off the 0.0000 it sits at for every base and instruct
configuration in `docs/pictures/README.md`?

machine: Apple M2, macOS (Darwin 25.3.0 arm64), Metal via Burn 0.20 / wgpu.
**GPU contended** — jacobi2000's `target/release/jacobi` was running
throughout (`ps -A -o comm | grep -E 'target/release/(jacobi|llm-life)'` was
non-empty at launch). Every timing below is **provisional**.
llm-life commit: `63c8333`, llm-web commit: `044b47d` (branch `llm-life`).

command:

```
./target/release/llm-life train \
  --gguf ~/Code/idle-intelligence/models/gguf/Qwen2.5-0.5B-GGUF/Qwen2.5-0.5B.Q4_0.gguf \
  --tokenizer ~/Code/idle-intelligence/models/hf/Qwen2.5-0.5B/tokenizer.json \
  --size 16 --steps 60 --lr 1e-4 --rank 8 --alpha 16 --seed 1 \
  --eval-every 20 --eval-grids 4 --max-secs 1500 \
  --out artifacts/lora-b-smoke.bin --run-doc docs/runs/2026-09-19-ft-1.md
```

Grid size 16x16, not the 32x32 the plan named: a 32x32 step measured ~100 s
against 16x16's ~6 s, and the adapter is size-independent here — a cell
attends to the 68-token prefix plus its own 9-cell neighbourhood and to
nothing else, so the softmax is over 77 keys whatever the grid is. Training
at 16x16 and evaluating at 64x64 is the same model.

One grid is one step: no batch axis, 256 labelled cells per forward.

## Note

The saved adapter (`artifacts/lora-b-smoke.bin`, not committed) is the
**step-60** one, which is not the best one: step 40 is. With one 256-cell
grid per step and no gradient accumulation, the run oscillates between the
two failure modes rather than converging — step 20 and step 60 over-predict
alive (`death-crowded` 0.0000, and at step 60 `death-lonely` drops to 0.65),
step 40 gets every class. lr 1e-4 is too large for this batch size; run 2
(`2026-09-19-ft-2.md`) repeats at 3e-5.

The result the run was for still holds and is the first time it has held in
this repo: **birth and survival leave 0.0000**. At step 40 the model gets
every one of the six neighbourhood classes, IoU 0.9717 against the 0.0000 of
every base and instruct row in `docs/pictures/README.md`, after 40 steps and
about four minutes of a contended GPU on 1.08M trainable parameters (rank-8
LoRA on q/k/v/o, 0.22% of the model).
