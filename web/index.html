All timings provisional: shared GPU. LLM mode binarizes p(alive) with a label-free threshold (default: Otsu 1979) before painting the LLM of Life panel and feeding it forward as the next generation's input — z-score (mean + k·std) is selectable via window.__app.setThreshold('zscore', k), no UI setting. Variant B is one forward over the whole 64×64 grid; variant A is 16×16, one forward per chunk of 64 cells against a few-shot prefix resident in the KV cache.
